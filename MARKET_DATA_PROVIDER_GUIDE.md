# MarketPulse AI — Market Data Provider Integration Guide
**Regulatory & Integrity Standard:** Financial honesty, explicit feed provenance, and zero price fabrication.

---

## 1. Provider Adapter Architecture

MarketPulse AI incorporates a multi-provider abstraction layer (`ProviderManager`) that decouples internal consumption (charts, anomaly radar, forecasting) from the underlying transport protocol and data supplier.

```
                           ┌───────────────────────────┐
                           │      ProviderManager      │
                           │  (backend/src/modules/    │
                           │         provider/)        │
                           └─────────────┬─────────────┘
                                         │
                 ┌───────────────────────┼───────────────────────┐
                 │                       │                       │
                 ▼                       ▼                       ▼
      ┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐
      │   UpstoxV3Adapter   │ │    TejHQAdapter     │ │  SimulatedAdapter   │
      │  (Official Broker)  │ │   (Daily Bhavcopy)  │ │ (Geometric Brownian)│
      ├─────────────────────┤ ├─────────────────────┤ ├─────────────────────┤
      │ Mode: LIVE          │ │ Mode: END_OF_DAY    │ │ Mode: SIMULATED     │
      │ Protocol: WebSocket │ │ Protocol: HTTP REST │ │ Protocol: In-Memory │
      │ Data: Protobuf Feed │ │ Data: Daily OHLCV   │ │ Data: Realistic GBM │
      │ Limit: 100 Equities │ │ Cost: Free          │ │ Cost: Free          │
      └─────────────────────┘ └─────────────────────┘ └─────────────────────┘
```

## 2. Supported Market Data Adapters

### 1. `UpstoxV3Adapter` (`LIVE` Mode)
- **Status:** Integrated via official Upstox V3 SDK.
- **Protocol:** Binary WebSocket stream with Protocol Buffers decoding.
- **Authentication:** OAuth 2.0 Authorization Code flow. Daily access token exchange.
- **Subscription Management:**
  - Upstox imposes an account capacity limit of **100 concurrent instrument subscriptions** per streamer connection.
  - An internal **Priority LRU Queue** manages active subscriptions. When a user requests viewing the 101st instrument, the least recently viewed background instrument is automatically evicted from the feed.
- **Stale Feed Detection:** If no tick is received for an active equity within **15 seconds** during market hours, the feed status degrades to `STALE_FEED` with visual UI warning.
- **Safety Rule:** Upstox is **only** labeled `LIVE` when its WebSocket connection is authenticated, open, and actively receiving ticks. If connection drops, the system transitions to disconnected status.

### 2. `TejHQAdapter` (`END_OF_DAY` Mode)
- **Status:** Integrated and verified.
- **Endpoint:** `https://api.tejhq.dev`
- **Scope:** Complete daily closing bhavcopy and historical candles across all NSE and BSE equity shares.
- **Timestamping:** Explicitly dated with the publishing trading session date in `Asia/Kolkata` time (`DD/MM/YYYY, HH:MM:SS IST`).
- **Safety Rule:** TejHQ bhavcopy data is strictly identified as `END_OF_DAY` and **never** mislabeled as live intraday ticks.

### 3. `SimulatedAdapter` (`SIMULATED` Mode)
- **Status:** Default out-of-the-box development and demonstration mode.
- **Methodology:** Geometric Brownian Motion (GBM) with realistic volatility clustering, drift parameters, and stochastic volume distribution.
- **Zero Dependencies:** Requires no broker API keys, third-party internet access, or paid accounts.
- **Safety Rule:** Every tick and candle generated by this adapter carries the immutable tag `source_mode: 'SIMULATED'`. The UI displays a prominent yellow `SIMULATED` pill.

### 4. `HistoricalReplayAdapter` (`HISTORICAL_REPLAY` Mode)
- **Status:** Integrated.
- **Methodology:** Chronological playback of genuine historical candles stored in PostgreSQL.
- **Playback Speeds:** Selectable at 1x, 5x, 10x, or 60x real-time speed for backtesting and algorithm verification.

## 3. Switching Data Modes

You can configure the active data mode via `.env`:
```env
APP_MODE=SIMULATED       # Options: SIMULATED, END_OF_DAY, LIVE, HISTORICAL_REPLAY
MARKET_DATA_PROVIDER=tejhq # Options: tejhq, upstox, simulated
```

Or switch dynamically at runtime via the authenticated provider management API:
```bash
curl -X POST http://localhost:5000/api/provider/mode \
  -H "Authorization: Bearer <ADMIN_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"mode":"END_OF_DAY"}'
```

## 4. Upstox OAuth2 Onboarding & Verification

To activate genuine live streaming for NSE/BSE equities:
1. Register a developer app on the [Upstox Developer Portal](https://upstox.com/developer/).
2. Set the redirect URI to:
   ```
   http://localhost:5000/api/provider/upstox/callback
   ```
3. Populate `.env`:
   ```env
   MARKET_DATA_PROVIDER=upstox
   APP_MODE=LIVE
   UPSTOX_CLIENT_ID=your_api_key
   UPSTOX_CLIENT_SECRET=your_api_secret
   ```
4. Authenticate via `/api/provider/upstox/authorize` each morning before market open (09:15 IST) to acquire the daily session token.
